THE ATLAS, EXPLAINED

First it answers “what do I need to craft this from what I have now?” — then it is a place to browse every crafting, item and skill tree.

Planning

“From nothing” — every item panel opens with the plan: Gather (raw materials, total quantities), Build (stations), Train (skills + levels), and the Critical chain — the longest prerequisite run that gates your progress. Click any chip to jump.

Path to… — pick a starting item, press the button, then tap a target on the map or pick one from the gold-pulsing search box. The shortest material route lights up with numbered steps.

Waypoint checklist — cycle the plan button to plan: waypoint: the remaining work becomes an ordered, checkable list (Gather → Build → Craft) from your ledger to the item. Check a step off as you craft it and the plan re-runs; the header tracks X of N done · re-plans per item, with a reset.

Owning things

✓ Owned — mark items you have in their panel. Flip the Possessions chip to show only what you can reach from what you own. Counts persist in your browser.

Focus

Shift+Click isolates a crafting tree — outputs only by default (what the item enables; the full both-way walk can swallow most of the map for hub items). Trace inputs highlights every ingredient behind an item. Depth limits how far isolation walks (blank = all), and the direction select adds inputs only or restores up + down. The legend (top left) tames the map: every item kind and all link kinds toggle there — Show everything restores it all at once. Dead ends shows items nothing crafts. Found in rows in a panel jump to green region hubs (map aids from the wiki's location prose — their links start hidden; enable Region links in the legend).

Layouts

24 algorithms, grouped force / trees / simple. Similar ones ship on purpose — the same graph renders differently under each, and subtrees can prefer different algorithms than the whole. force-directed off = spread presets; animate off = jump straight to the result; saved positions applies the bundled snapshot instantly (marked · saved). The density slider tunes elk layer spacing live (50–200%), and 💾 saves the current arrangement as a custom snapshot that boots instantly (marked · custom; ✕ clears it). ⤓ downloads that snapshot as a JSON file to share — merged ones ship with the atlas for every visitor (marked · curated). worker layout computes heavy layouts in a background thread so the page keeps responding; if a worker can't run a layout it falls back to the main thread automatically. The gold Arranging pill spins and shows a live progress bar until the layout settles; algorithms that can't run here (rooted-tree ones on the full map) tell you so instead of failing silently.

Keys

/ search · ? help · F fit · Esc cancel path → clear isolation → close panel.

Map

Wheel = zoom, drag = pan. The breadcrumb traces lineage; the minimap (bottom right) shows where you are — click it to jump.
